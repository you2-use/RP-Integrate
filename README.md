# RP방 합치기

Marinara Engine에서 같은 캐릭터 구성의 RP방을 원하는 순서로 합쳐 새 RP방을 만드는 확장입니다. 원본 RP방을 유지하면서 메시지와 대체 답변을 가져오고, Chat Summary·AI 모델과 토큰 정보·생성한 삽화를 선택해 함께 가져올 수 있습니다.

- 공개 버전: **v1.3.0**
- 작업 기준: **Marinara Engine v2.5.0**
- 설치 방식: GitHub 확장 관리자 또는 ZIP 직접 설치

[v1.3.0 ZIP 다운로드](https://github.com/you2-use/RP-Integrate/releases/download/v1.3.0/RP-Integrate.personal-extension.zip) · [릴리스 안내](https://github.com/you2-use/RP-Integrate/releases/tag/v1.3.0)

## 주요 기능

- 선택한 RP방의 순서를 드래그 또는 ↑ / ↓ 버튼으로 정합니다.
- 메시지, 대체 답변, 번역, 지원되는 비공개 표시 정보를 가져옵니다.
- Chat Summary를 가져오고 새 메시지 ID에 연결합니다.
- 연결할 메시지가 없어진 요약은 선택에 따라 본문만 보존합니다.
- 현재 활성 답변의 AI 모델·토큰 정보를 선택해 가져옵니다.
- 메시지와 대체 답변에 첨부된 갤러리 삽화를 새 방 소유로 복사합니다.

## 설치 전 준비

1. 서버에서 외부 확장이 잠겨 있다면 Marinara 설치 폴더의 `.env`에 `ENABLE_EXTERNAL_EXTENSIONS=true`를 설정하고 Marinara를 재시작합니다. 다른 사람이 운영하는 서버라면 서버 운영자에게 요청하세요.
2. **설정 → 고급 → 위험 구역 → 타사 확장 가져오기 허용**을 켭니다.
3. **설정 → 애드온 → 외부 확장**을 엽니다.

언어 팩에 따라 메뉴가 영어로 표시될 수 있습니다. 가져온 확장은 꺼진 상태로 저장되며 코드와 권한을 검토한 뒤 실행을 승인해야 합니다.

## 설치 방법 1: GitHub 확장 관리자

GitHub 확장 관리자가 설치되어 있고 켜져 있어야 합니다.

1. 관리자에서 **확장 추가**를 누릅니다.
2. 저장소 주소 입력란에 아래 주소를 붙여 넣고 **패키지 찾기**를 누릅니다.

   ```text
   https://github.com/you2-use/RP-Integrate
   ```

3. 설치할 패키지에서 **manifest.json**을 선택하고 **내용 확인**을 누릅니다.
4. 이름이 **RP방 합치기**, 버전이 **1.3.0**인지 확인하고 **설치**를 누릅니다.
5. **검토 후 켜기**를 누르고 코드와 **전체 페이지 접근** 권한을 검토한 뒤 Marinara의 확인창에서 실행을 승인합니다.

공개 저장소이므로 GitHub 로그인이나 토큰이 필요하지 않습니다. 관리자에서는 릴리스 ZIP 대신 저장소의 `manifest.json`을 선택하세요.

## 설치 방법 2: ZIP 다운로드 후 직접 설치

1. [RP-Integrate.personal-extension.zip 다운로드](https://github.com/you2-use/RP-Integrate/releases/download/v1.3.0/RP-Integrate.personal-extension.zip)를 눌러 파일을 받습니다. **ZIP은 미리 풀지 않습니다.**
2. **설정 → 애드온 → 외부 확장 → 확장 파일 가져오기**를 누릅니다. 영어 화면에서는 **Import Extension File**입니다.
3. 받은 ZIP을 선택하고 **RP방 합치기 / 1.3.0**을 확인한 뒤 가져오기를 완료합니다.
4. **검토 및 실행 / Review and run**에서 코드와 전체 페이지 접근 권한을 확인하고 실행을 승인합니다.

GitHub 확장 관리자가 기본 가져오기 버튼을 숨겼다면 관리자의 **확장 추가 → 파일에서**로 ZIP을 선택하세요. 같은 확장을 중복으로 켜지 마세요.

## 사용 방법

1. 왼쪽 채팅 목록의 **RP방 탭**에서 Marinara의 **다중 선택**을 켭니다.
2. 같은 캐릭터 구성의 RP방을 **2개 이상** 선택합니다.
3. 다중 선택 작업 표시줄에 추가된 **병합하기**를 누릅니다.
4. **새 RP방 제목**을 입력하고 **병합 순서**에서 드래그 또는 ↑ / ↓ 버튼으로 방 순서를 정합니다.
5. 필요한 가져오기 옵션을 선택합니다.
6. **최종 확인**에서 순서·메시지 수·옵션·제목을 확인하고 **조립 시작**을 누릅니다.
7. 완료 안내를 확인하고 **새로고침**을 눌러 새 RP방을 엽니다. 페르소나·프리셋·연결 등 필요한 설정은 새 방에서 지정합니다.

| 옵션 | 동작 |
| --- | --- |
| Chat Summary 가져오기 | 요약이 있는 방을 선택하면 처음에 켜집니다. 요약과 지원되는 숨김 메시지 연결을 새 방으로 옮깁니다. |
| 연결할 수 없는 요약은 본문만 가져오기 | 처음에는 꺼집니다. 필요한 경우에만 표시됩니다. 요약 본문·제목·순서·활성 상태를 유지하고 확인할 수 없는 메시지 ID·개수·범위를 제거합니다. |
| AI 모델·토큰 정보 가져오기 | 처음에는 꺼집니다. 현재 활성 답변의 생성 정보만 가져옵니다. |
| 생성한 삽화 가져오기 | 처음에는 꺼집니다. 켜면 갤러리 삽화를 확인하고 새 방 소유로 복사합니다. 끄면 해당 삽화 첨부를 제외합니다. |

## 저장 방식과 중요한 동작

- **조립 시작**을 누르면 새 RP방을 현재 Marinara 서버에 만들고 바로 저장합니다. 별도의 저장 버튼은 없습니다. **새로고침**은 저장된 방을 화면에서 확인하는 단계입니다.
- 원본 RP방을 덮어쓰거나 삭제하지 않습니다. 같은 제목을 입력해도 별도의 새 방을 만듭니다.
- 방 순서대로 메시지를 이어 붙입니다. 메시지를 시간순으로 재정렬하거나 중복 내용을 자동 제거하지 않습니다.
- 페르소나, 프리셋, 연결 설정, User Note 등 방 설정은 복사하지 않습니다.
- 조립 전에는 원본을 읽고 결과를 미리 확인합니다. 원본이나 선택 상태가 바뀌면 다시 확인해야 할 수 있습니다.
- AI 모델·토큰 정보 일부가 복원되지 않으면 완료 화면에 누락 개수를 표시합니다.
- 삽화 복사·연결 또는 필수 검증에 실패하면 이번 작업에서 만든 새 방의 정리를 시도하고 결과를 표시합니다. 정리 여부를 확인할 수 없다는 안내가 나오면 RP방 목록을 먼저 확인하세요.
- 새 방 생성과 이미지 업로드는 응답이 불확실해도 자동 반복하지 않습니다. 중복 생성을 피하려면 오류 안내와 방 목록을 확인한 뒤 다시 시도하세요.

## 지원 형식과 제한

- Marinara 안에 저장된 RP방을 합칩니다. 외부 채팅 파일을 직접 선택해 합치는 기능은 없습니다.
- 캐릭터 구성이 같은 방만 지원합니다. 새 방 제목은 200자 이하입니다.
- 지원하는 메시지 역할은 `user`, `assistant`, `system`, `narrator`입니다. 알 수 없는 데이터나 잘못된 ID·요약 연결은 병합을 차단할 수 있습니다.
- 삽화 대상은 메시지와 모든 대체 답변의 `galleryId` 또는 `/api/gallery/file/` 주소를 가진 첨부 이미지입니다. PNG·JPEG·WebP·GIF·AVIF를 지원하며 이미지당 최대 20 MiB입니다.
- 삽화는 재생성·재압축하지 않습니다. 프롬프트·제공자·모델·크기 정보를 보존하고 새 갤러리 ID·경로·등록일을 만듭니다. 같은 갤러리 이미지의 여러 참조는 한 번만 복사합니다.
- 갤러리에만 남아 있는 이미지, 배경, 캐릭터·페르소나 갤러리 전체, 동영상은 삽화 복사 대상이 아닙니다. 본문의 HTML·Markdown 이미지 링크도 이 옵션으로 복사하지 않습니다.
- 일반 인라인 업로드·외부 이미지 URL·다른 첨부파일은 지원되는 메시지 데이터로 유지합니다. 원본 방 소유의 지원되지 않는 첨부는 병합을 막을 수 있습니다.
- 본문만 가져오기는 없어진 메시지를 복구하거나 요약 범위를 추측하지 않습니다.
- 병합 중 만드는 JSONL 데이터가 250 MiB를 초과하면 중단합니다. 브라우저 메모리나 서버 제한에 따라 더 작은 작업도 실패할 수 있습니다.
- 삽화 무결성 검증에는 Web Crypto를 지원하는 브라우저와 로컬 주소 또는 HTTPS 연결이 필요합니다.
- Marinara Engine v2.5.0에서 작업한 확장입니다. 다른 버전에서 화면·API 구조가 바뀌면 호환성 수정이 필요할 수 있습니다.

## 권한과 데이터 처리

**전체 페이지 접근(`full_page_access`)** 권한을 요청합니다. RP방 목록에 버튼을 넣고 현재 세션의 Marinara API로 방·메시지·요약·갤러리 데이터를 읽고 새 방을 저장하기 위해 필요합니다. 이 권한은 페이지 내용, 브라우저 저장소, 네트워크 API와 현재 세션에 접근할 수 있으므로 코드를 검토한 뒤 승인하세요.

병합 처리는 브라우저에서 진행하며 요청은 현재 Marinara 서버로 보냅니다. 외부 AI 서비스나 별도의 수집 서버로 대화와 이미지를 전송하지 않습니다. 삽화 옵션이 꺼져 있으면 갤러리 이미지 조회·업로드 요청을 보내지 않습니다. 켜져 있으면 이미지를 읽어 무결성을 확인하고 같은 Marinara 서버에 새 방 소유로 업로드합니다.

확장을 끄거나 삭제해도 이미 저장한 병합 RP방은 유지됩니다.

## 업데이트와 수정 기록

GitHub 확장 관리자로 설치했다면 해당 항목의 **업데이트 확인**에서 새 코드를 확인하고 **업데이트 설치**를 누릅니다. ZIP으로 설치했다면 새 ZIP을 받아 같은 가져오기 화면에서 기존 **RP방 합치기** 항목을 업데이트합니다. GitHub 업데이트를 사용하려면 관리자에서 이 저장소를 연결하세요.

업데이트는 꺼진 상태로 저장됩니다. **Save Disabled Update**도 같은 의미입니다. 새 코드와 권한을 검토하고 다시 실행을 승인한 뒤 페이지를 새로고침하세요. 기존 설정과 저장 데이터는 유지됩니다. 버전이나 README만 바뀐 경우에는 관리자가 코드 업데이트로 표시하지 않을 수 있습니다.

## 문제 해결

| 증상 | 해결 방법 |
| --- | --- |
| 외부 확장 메뉴가 없거나 가져오기가 잠겨 있어요. | 서버의 `ENABLE_EXTERNAL_EXTENSIONS=true`와 위험 구역의 타사 확장 허용을 확인하세요. |
| 패키지를 찾지 못해요. | 저장소 주소를 확인하고 최상위 `manifest.json`을 선택하세요. 릴리스 ZIP 대신 저장소 파일로 설치하세요. |
| 병합하기 버튼이 없어요. | 실행 승인과 활성화 상태를 확인하고 페이지를 새로고침하세요. RP방 탭에서 다중 선택을 켜세요. |
| 버튼이 비활성화되거나 선택 상태 오류가 나와요. | 다중 선택을 종료했다가 다시 켜고 같은 캐릭터 구성의 방을 2개 이상 선택하세요. |
| 요약 때문에 진행할 수 없어요. | 안내를 확인하고 본문만 가져오기를 켜거나 Chat Summary 가져오기를 끄세요. 잘못된 형식·ID는 본문만 가져오기로도 해결되지 않을 수 있습니다. |
| 삽화 확인이 실패해요. | 원본 갤러리 파일과 연결 상태를 확인하세요. 로컬 주소 또는 HTTPS로 접속하거나 삽화 가져오기를 끄고 다시 확인하세요. |
| 일부 AI 모델·토큰 정보가 없어요. | 활성 답변 정보만 가져옵니다. 완료 화면의 복원·누락 개수를 확인하세요. |
| 새 방이 보이지 않아요. | 완료 화면에서 새로고침하세요. 오류가 났다면 정리 결과와 RP방 목록을 먼저 확인하세요. |
| 업데이트 후 버튼이 사라졌어요. | 새 코드와 권한을 다시 검토해 실행을 승인하고 페이지를 새로고침하세요. |

## 파일 구성

```text
RP-Integrate/
├─ manifest.json
├─ extension.js
├─ preview.js
├─ illustrations.js
├─ phase3.js
├─ extension.css
├─ preview.css
├─ README.md
└─ CHANGELOG.md
```

실행에 필요한 파일이 포함되어 있어 npm 설치나 TypeScript 컴파일이 필요하지 않습니다.
